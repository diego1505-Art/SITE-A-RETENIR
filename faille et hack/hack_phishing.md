## Installation

### Mettre à jour le système

```bash
sudo apt update
sudo apt upgrade -y
```
### installer et ouvrir le tool :  

```bash
git clone --depth=1 https://github.com/htr-tech/zphisher.git
cd zphisher
bash zphisher.sh
```
